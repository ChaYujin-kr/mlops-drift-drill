# [MLOps 실습 시리즈] 5. 경보가 울리면 재학습? 판정 기준부터 바꿔보자

4편에서 모델은 망가지지 않았다는 걸 확인했다. 그럼 아무것도 안 해도 될까? 돈으로 계산해 보면 다르다.

## 상황 가정

이 모델로 50K 초과 고객에게 프리미엄 카드 안내를 보낸다.
- 안내 1건 비용: **2,000원**
- 50K 초과 고객이 가입하면 이익: **150,000원**

## 비용으로 판정 기준 정하기

모델은 확률을 내고, 기본 판정 기준은 50%다. 그런데 이 숫자는 비용을 전혀 반영하지 않는다.

안내를 보냈을 때 기대 이익은 `p × 150,000 − 2,000`이다. 이게 0보다 크려면:
```
p > 2,000 / (2,000 + 150,000) ≈ 1.3%
```
일반식은 `p* = C_FP / (C_FP + C_FN)`. 놓쳤을 때 손해가 보냈을 때 비용보다 75배 크니, 확률이 1.3%만 넘어도 보내는 게 이득이다.

## 판정 기준만 바꿔보기 (모델은 그대로)

| 판정 기준 | 드리프트 구간 순이익 |
|---|---|
| 50% (기본) | 293만 원 |
| 30% | 452만 원 |
| **10%** | **524만 원** |
| 1.3% (p*) | 504만 원 |
| 전원 발송 | 335만 원 |

재학습도, 새 라벨도 없이 **1.8배**가 됐다. p*보다 10%가 조금 나은 이유는 랜덤포레스트의 확률이 실제 확률과 정확히 맞지 않아서다(확률 보정 문제).

## 재학습과 비교

나중에 도착한 라벨 3,000건으로 재학습한 모델과 비교했다.

| | AUC | 50% 기준 | 10% 기준 |
|---|---|---|---|
| 구모델 | 0.950 | 764만 원 | 1,216만 원 |
| 신모델 (재학습) | 0.952 | 765만 원 | 1,202만 원 |

재학습 효과는 많아야 십여만 원. 같은 구모델에서 기준만 바꾸면 **약 450만 원**.

AUC는 "사람들을 얼마나 잘 줄 세우는가"만 봐서 판정 기준과 무관하다. 돈은 판정 기준에서 갈린다.

## 실패 비용은 도메인마다 다르다

| 도메인 | 잘못 잡으면 | 놓치면 | 실무 방법 |
|---|---|---|---|
| 마케팅 | 발송비 | 놓친 매출 | 일부러 안 보내는 홀드아웃 그룹으로 놓친 것을 잰다 |
| 의료 | 불필요한 검사 | 진단 지연 | Decision Curve Analysis |
| 보이스피싱 | 정상 거래 차단, 민원 | 피해액 | 경고 → 추가 인증 → 지연이체 → 차단처럼 단계를 나눈다 |

## 한 줄 정리

경보가 울리면 재학습보다 먼저 판정 기준을 본다. 가장 싼 개선이 가장 컸다.
